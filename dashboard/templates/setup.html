save credentials once. they live in ~/.viralman/.env (chmod 600). secrets piped via /api/creds/manual; never logged to chat.

Twitter / X

redirect URI to register: http://localhost:8765/oauth/twitter/callback
  1. open developer.twitter.com (logged into the account you want viralman to post from).
  2. create a new project + app. App name must be globally unique on X (try viralman-<your-handle>).
  3. "User authentication settings" → set up. App permissions: Read and write ← important. Type: Web App. Callback URI: http://localhost:8765/oauth/twitter/callback. Website: any valid URL.
  4. "Keys and tokens" tab. Save the four secrets below. Regenerate the Access Token AFTER setting Read+Write — otherwise tokens are read-only.

Reddit

redirect URI to register: http://localhost:8765/oauth/reddit/callback
  1. open reddit.com/prefs/apps.
  2. "create another app" at the bottom.
  3. name: viralman. type: web app (for OAuth) or script (for legacy username+password). redirect uri: http://localhost:8765/oauth/reddit/callback.
  4. copy the short string under the app name (= client id) and the "secret" field.
  5. 2FA on Reddit blocks PRAW password auth (script-app path). Use OAuth or a dedicated posting account.

LinkedIn

redirect URI to register: http://localhost:8765/oauth/linkedin/callback
  1. open linkedin.com/developers/apps.
  2. create a new app. you'll need a Page to associate it with — any of yours works.
  3. "Auth" tab. Add redirect URL: http://localhost:8765/oauth/linkedin/callback.
  4. "Products" tab. Request access to Sign In with LinkedIn using OpenID Connect and Share on LinkedIn. Approval is automatic for personal use.
  5. "Auth" tab → copy Client ID and Client Secret.
  6. Tokens expire after 60 days; the dashboard will tell you when to re-login.

Gitmail — SMTP + GitHub + LLM provider

Three credential bundles. Save whichever ones apply.

1. GitHub token (raises the API rate limit from 60 → 5000/hour)

  1. open github.com/settings/tokens.
  2. "Generate new token" → fine-grained.
  3. name: viralman-gitmail. expiration: anything (90 days is fine).
  4. repository access: Public Repositories (read-only). permissions: defaults are enough.
  5. copy and save.

2. SMTP — Gmail example

  1. open myaccount.google.com/apppasswords (2FA must be on).
  2. create a new app password named viralman. copy the 16-char password.
  3. fields below: host smtp.gmail.com, port 587, security starttls. user = your Gmail address. password = the 16-char one.
  4. Gmail caps at ~500 emails/day per account. For larger sends use SendGrid / Mailgun / Amazon SES.
